# 📱 Catatan Keuangan Harian Kalian Yang Sulit Itu

Aplikasi pencatat keuangan harian modern berbasis Android yang dibangun menggunakan **Jetpack Compose**, **Room Database**, dan arsitektur **MVVM**.

---

## ✨ Fitur Utama
-  **Pencatatan Cepat**: Input pemasukan dan pengeluaran harian dengan format nominal otomatis.
-  **Statistik Visual**: Grafik Pie Chart interaktif untuk memantau alokasi pengeluaran per kategori.
-  **Riwayat Transaksi**: Filter dan pantau histori keuangan berdasarkan bulan.
-  **Cadangkan & Pulihkan (Offline)**: Ekspor dan impor data transaksi langsung ke format CSV yang kompatibel dengan Microsoft Excel & Google Sheets.

---

## 🛠️ Tech Stack
- **UI**: Jetpack Compose (Material 3)
- **Database**: Room Database (SQLite)
- **Architecture**: MVVM (Model-View-ViewModel)
- **Language**: Kotlin
